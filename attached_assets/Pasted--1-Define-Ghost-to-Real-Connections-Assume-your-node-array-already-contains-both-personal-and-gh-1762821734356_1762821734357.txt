⚙️ 1. Define Ghost-to-Real Connections

Assume your node array already contains both personal and ghost nodes:

// Example node schema
{
  id: "Meal Prep",
  type: "personal",  // or "ghost"
  x, y,
  vector: [0.3, 0.6, 0.9], // optional embedding or synthetic position
}

Compute nearest real node for each ghost

You can use either Euclidean distance in layout space or cosine similarity if you have embeddings.

Simple geometric proximity (works for MVP):

function findNearestPersonalNode(ghost, nodes) {
  const personalNodes = nodes.filter(n => n.type === "personal");
  let minDist = Infinity;
  let nearest = null;

  personalNodes.forEach(n => {
    const dx = ghost.x - n.x;
    const dy = ghost.y - n.y;
    const dist = Math.sqrt(dx*dx + dy*dy);
    if (dist < minDist) {
      minDist = dist;
      nearest = n;
    }
  });

  return nearest;
}


Build the overlay link list:

const ghostLinks = ghostNodes.map(g => ({
  source: g.id,
  target: findNearestPersonalNode(g, nodes).id,
  type: "ghost-link"
}));


Then append this to your global links array before running your force simulation.

🎨 2. Render Dashed Ghost Edges

After your main link render block, add:

svg.selectAll(".ghost-link")
  .data(ghostLinks)
  .enter()
  .append("line")
  .attr("class", "ghost-link")
  .style("stroke", "#bbb")
  .style("stroke-width", 1)
  .style("stroke-dasharray", "3,3")
  .style("opacity", 0.4);


These edges should be below your solid links:

svg.selectAll(".ghost-link").lower();

🟠 3. Render Ghost Nodes Themselves
svg.selectAll(".ghost-node")
  .data(ghostNodes)
  .enter()
  .append("circle")
  .attr("class", "ghost-node")
  .attr("r", 6)
  .style("fill", "none")
  .style("stroke", "#f5a623")
  .style("stroke-width", 1.5)
  .style("stroke-dasharray", "4,2")
  .style("opacity", 0.35)
  .on("mouseover", showTooltip)
  .on("mouseout", hideTooltip)
  .on("click", promoteGhostNode);

💬 4. Tooltip Logic

Add small floating div tooltip:

const tooltip = d3.select("body")
  .append("div")
  .attr("class", "tooltip")
  .style("position", "absolute")
  .style("padding", "6px 8px")
  .style("background", "rgba(0,0,0,0.7)")
  .style("color", "#fff")
  .style("border-radius", "4px")
  .style("pointer-events", "none")
  .style("opacity", 0);

function showTooltip(event, d) {
  tooltip.transition().duration(150).style("opacity", 1);
  tooltip.html(`
    <strong>${d.id}</strong><br/>
    Trending nearby • ${d.popularity}% overlap
  `)
  .style("left", (event.pageX + 8) + "px")
  .style("top", (event.pageY - 24) + "px");
}

function hideTooltip() {
  tooltip.transition().duration(200).style("opacity", 0);
}

🔄 5. Click → Promote Ghost to Real Node

When users click a ghost node, convert it into a full personal node:

function promoteGhostNode(event, d) {
  d.type = "personal";
  d3.select(this)
    .transition()
    .duration(400)
    .style("stroke-dasharray", "none")
    .style("opacity", 1)
    .style("fill", "#fff");

  // optional: persist this change to backend
  // addNodeToUserGraph(d.id)
}
